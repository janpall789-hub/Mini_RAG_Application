Data Structures and Algorithms - Levels 1 to 3 Roadmap

Level 1: Basic Foundations
- Linear Data Structures: Arrays, Strings, Linked Lists, Stacks, Queues.
- Basic Algorithms: Linear Search, Binary Search, Bubble/Insertion/Selection Sort.
- Time & Space Complexity: Big-O notation, Big-Theta, Big-Omega.

Level 2: Intermediate Data Structures & Algorithmic Patterns
- Trees & Graphs: Binary Trees, Binary Search Trees (BST), Graph Representations (Adjacency Matrix/List).
- Traversal Strategies: Breadth-First Search (BFS), Depth-First Search (DFS).
- Core Techniques: Two Pointers, Sliding Window, Recursion, Backtracking.

Level 3: Advanced Optimization & Complex Structures
- Advanced Graphs: Dijkstra's, Bellman-Ford, Floyd-Warshall, Topological Sort, Disjoint Set Union (DSU).
- Dynamic Programming: Memoization (Top-down), Tabulation (Bottom-up), Knapsack, LCS.
- Advanced Trees: Tries, Segment Trees, Fenwick Trees (Binary Indexed Trees).

## 40 Basic Coding Problems and Answers

### 1. Find the largest element in an array

**Question:** Find the largest number in an array.

**Answer:** Traverse the array and maintain a variable containing the largest value found so far.

**Example:** `[10, 25, 7, 40, 15]` → `40`

---

### 2. Find the smallest element in an array

**Question:** Find the smallest number in an array.

**Answer:** Traverse the array and continuously update the minimum value.

**Example:** `[10, 25, 7, 40, 15]` → `7`

---

### 3. Find the sum of array elements

**Question:** Calculate the sum of all elements in an array.

**Answer:** Initialize `sum = 0` and add every element to it.

**Example:** `[1, 2, 3, 4, 5]` → `15`

---

### 4. Find the average of an array

**Question:** Find the average of all numbers in an array.

**Answer:** Divide the sum of all elements by the number of elements.

**Example:** `[10, 20, 30]` → `20`

---

### 5. Reverse an array

**Question:** Reverse the elements of an array.

**Answer:** Use two pointers, one at the beginning and one at the end, and swap elements until they meet.

**Example:** `[1, 2, 3, 4]` → `[4, 3, 2, 1]`

---

### 6. Search for an element

**Question:** Check whether a given element exists in an array.

**Answer:** Traverse the array and compare each element with the target.

**Example:** Search `5` in `[2, 5, 8]` → Found.

---

### 7. Count even numbers

**Question:** Count the number of even elements in an array.

**Answer:** Traverse the array and increment a counter whenever `number % 2 == 0`.

**Example:** `[1, 2, 4, 7, 8]` → `3`

---

### 8. Count odd numbers

**Question:** Count the number of odd elements in an array.

**Answer:** Traverse the array and increment a counter for every odd number.

**Example:** `[1, 2, 4, 7, 8]` → `2`

---

### 9. Find the second largest element

**Question:** Find the second largest distinct element in an array.

**Answer:** Track the largest and second-largest distinct values while traversing the array.

**Example:** `[10, 20, 5, 30, 15]` → `20`

---

### 10. Remove duplicates from an array

**Question:** Remove duplicate elements from an array.

**Answer:** Use a set or another appropriate data structure to keep only unique values.

**Example:** `[1, 2, 2, 3, 3]` → `[1, 2, 3]`

---

### 11. Check whether an array is sorted

**Question:** Determine whether an array is sorted in ascending order.

**Answer:** Compare every element with the element immediately after it.

**Example:** `[1, 2, 3, 4]` → Sorted.

---

### 12. Count positive numbers

**Question:** Count positive numbers in an array.

**Answer:** Traverse the array and increment a counter whenever the element is greater than zero.

---

### 13. Count negative numbers

**Question:** Count negative numbers in an array.

**Answer:** Traverse the array and count elements smaller than zero.

---

### 14. Find the frequency of an element

**Question:** Count how many times a particular number occurs.

**Answer:** Traverse the array and increment the counter whenever the element equals the target.

**Example:** `[2, 3, 2, 5, 2]`, target `2` → `3`

---

### 15. Find duplicate elements

**Question:** Find elements that occur more than once.

**Answer:** Use a set to track visited elements and identify repeated values.

---

### 16. Linear Search

**Question:** Implement linear search.

**Answer:** Check each element sequentially until the target is found.

**Time Complexity:** `O(n)`

---

### 17. Binary Search

**Question:** Search for an element in a sorted array using binary search.

**Answer:** Repeatedly compare the target with the middle element and eliminate half of the search space.

**Time Complexity:** `O(log n)`

---

### 18. Swap two numbers

**Question:** Swap two numbers without changing their values incorrectly.

**Answer:** Use a temporary variable or a language-supported multiple assignment operation.

### 19. Find the factorial of a number

### 32. Implement a stack

### 33. Implement a queue

**Question:** Determine whether parentheses are balanced.

**Answer:** Use a stack. Push opening brackets and remove the matching opening bracket when a closing bracket is encountered.

### 35. Find the maximum of two numbers

**Question:** Find the larger of two numbers.

### 36. Find the maximum of three numbers

### 37. Sort an array

**Question:** Sort an array in ascending order.

**Answer:** Use a sorting algorithm such as bubble sort for learning purposes or an efficient built-in sorting method in production.

---

### 38. Bubble Sort

**Question:** Implement Bubble Sort.

**Answer:** Repeatedly compare adjacent elements and swap them when they are in the wrong order.

**Time Complexity:** `O(n²)` in the average and worst cases.

### 39. Find the missing number

**Question:** An array contains numbers from `1` to `n` with one number missing. Find the missing number.

**Answer:** Calculate the expected sum `n(n+1)/2` and subtract the actual array sum.

**Example:** `[1, 2, 4, 5]` → Missing number is `3`.

---

### 40. Find common elements

**Question:** Find elements common to two arrays.

**Answer:** Use a set or frequency structure to efficiently identify values present in both arrays.

**Example:** `[1, 2, 3, 4]` and `[3, 4, 5, 6]` → `[3, 4]`

## 17. Binary Search

```python
arr = [10, 20, 30, 40, 50]
target = 40

left = 0
right = len(arr) - 1

while left <= right:
    mid = (left + right) // 2

    if arr[mid] == target:
        print("Found at index", mid)
        break
    elif arr[mid] < target:
        left = mid + 1
    else:
        right = mid - 1
else:
    print("Not Found")
```

**Output:** `Found at index 3`

**Time Complexity:** `O(log n)`

## 38. Bubble Sort

```python
arr = [5, 2, 8, 1, 3]

n = len(arr)

for i in range(n):
    for j in range(0, n - i - 1):
        if arr[j] > arr[j + 1]:
            arr[j], arr[j + 1] = arr[j + 1], arr[j]

print(arr)
```

**Output:**

```text
[1, 2, 3, 5, 8]
```

**Time Complexity:** `O(n²)`
