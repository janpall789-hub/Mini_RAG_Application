HTML5 - Web Content Markup Language

1. Semantic HTML elements
Semantic elements clearly describe their meaning to both the browser and the developer (e.g., <header>, <nav>, <article>, <section>, <footer>). They improve SEO and accessibility.

2. Web Accessibility (WCAG & ARIA)
Accessible Rich Internet Applications (ARIA) attributes help communicate state and purpose to screen readers when standard semantic HTML is insufficient.

3. Canvas vs SVG
- SVG: Vector-based, DOM-accessible, scales smoothly without pixelation, suited for diagrams and icons.
- Canvas: Raster/pixel-based, rendered programmatically via JavaScript, ideal for graphics-intensive applications and high-frame-rate rendering.

HTML5 – Web Content Markup Language
How to Style Fonts with HTML5: Step-by-Step Guide for Students

HTML5 (HyperText Markup Language 5) is the standard markup language used to structure content on modern websites. HTML5 defines elements such as headings, paragraphs, links, images, buttons, forms, tables, and sections. HTML creates the structure, while CSS controls the visual appearance, including fonts.

As a frontend developer, students should learn an important rule: use HTML for meaning and structure, and CSS for styling. Although HTML has older tags such as <font>, the <font> element is obsolete and should not be used in modern HTML5 projects.



1. Create Your First HTML5 File

Create a file named:

index.html

Start with the basic HTML5 structure:

<!DOCTYPE html>
<html lang="en">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>Font Styling</title>
</head>

<body>

    <h1>Welcome to HTML5</h1>
    <p>This is my first webpage.</p>

</body>
</html>

Change Font Size Using CSS

HTML provides the content, while CSS changes its appearance.

<!DOCTYPE html>
<html>
<head>
    <title>Font Example</title>

    <style>
        p {
            font-size: 24px;
        }
    </style>
</head>

<body>

    <p>Hello Students!</p>

</body>
</html>

The font-size property controls the size of the text.

3. Change Font Family

You can specify which font should be used.

<style>
    body {
        font-family: Arial, sans-serif;
    }
</style>

You can also use a font stack:

body {
    font-family: Arial, Helvetica, sans-serif;
}

If Arial is unavailable, the browser tries Helvetica and then another sans-serif font.

4. Make Text Bold

For semantic importance, use <strong>:

<p>This is <strong>important text</strong>.</p>

You can also control visual weight using CSS:

p {
    font-weight: bold;
}

As a professional developer, prefer <strong> when the content is actually important rather than using HTML only for visual styling.

5. Italic Text

Use <em> when you want to emphasize text:

<p>This is <em>important information</em>.</p>

For purely visual styling:

p {
    font-style: italic;
}
6. Change Font Color

Use the CSS color property:

<p class="message">Welcome to Web Development!</p>

<style>
    .message {
        color: blue;
    }
</style>

You can use color names, hexadecimal values, RGB, HSL, and other CSS color formats.

8. Professional Guidance for Students

When learning frontend development, follow this order:

HTML5 → CSS3 → JavaScript → Responsive Design → Git/GitHub → APIs → Frontend Frameworks

Start by mastering HTML elements and semantic structure. Then learn CSS properties such as:

font-family
font-size
font-weight
font-style
line-height
letter-spacing
text-align
text-decoration
color

After learning the basics, students should build small projects such as a personal profile page, portfolio, login page, landing page, and responsive website.

Important Professional Tip

Do not use:

<font size="5" color="red">Hello</font>

The <font> element is obsolete in modern HTML. Instead, use:

<p class="title">Hello</p>

<style>
    .title {
        font-size: 30px;
        color: red;
    }
</style>

This separation of HTML structure + CSS presentation is a fundamental frontend development practice.
